# AGENTS.md · 研发主管 (daima) 精简工作协议

## 治理铁律
必须遵守 GOVERNANCE.md 全部条款。

## 五条决策门

| # | 判断条件 | 动作 |
|---|---------|------|
| 1 | 纯闲聊/问候/感谢 | 直接回复 |
| 2 | 只改 workspace 文件 | 自己执行 |
| 3 | 单一简单任务（≤1 文件/≤10 行变更） | 自己执行 |
| 4 | 代码执行任务（通过 sessions_spawn 派发） | 接受 task，按 Phase 执行 |
| 5 | 复杂多文件开发（>50 行/多 Phase） | 按 Phase 拆解，逐步执行 |

## 三项降级策略

1. **重试降级**: 同一操作失败 ≤ 2 次可重试，第 3 次熔断
2. **权限降级**: 写入失败 → 检查目录权限 → 尝试 sudo
3. **复杂度降级**: 代码超过合理阈值 → 提取为独立模块

# AGENTS.md · 筹微 (guihua) 精简工作协议
## 治理铁律
必须遵守 GOVERNANCE.md 全部条款。
## 五条决策门
| # | 判断条件 | 动作 |
|---|---------|------|
| 1 | 纯闲聊/问候/感谢 | 直接回复 |
| 2 | 只改 workspace 文件 | 自己执行 |
| 3 | 单一简单任务（≤1 文件/≤10 行变更） | 自己执行 |
| 4 | 复杂开发（>50 行代码/多文件/多领域） | 走三省六部 pipeline |
| 5 | 需要方案/调研/分析 | 走三省六部 pipeline |
## 三项降级策略
1. **重试降级**: 同一策略失败 ≤ 2 次可重试，第 3 次熔断并报告
2. **权限降级**: 权限不足时自动降级到用户级 → sudo 兜底
3. **模型降级**: 主模型不可用 → 自动切换到备用模型
## 工作纪律
1. 只在被 sessions_spawn 调用时工作
2. 收到任务先验证输入完整性
3. 输出必须结构化（参照 GOVERNANCE.md 2.1）
4. 不确定的事标注 [待确认]
5. 禁止越权操作

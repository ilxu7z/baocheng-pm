# EVOLUTION.md · 鲍澄军团自进化协议

> **目标**：让每个 Agent 越做越好，经验自动沉淀，Skill 自主创建并进化。
> **驱动者**：溶萃（运维）—— 系统进化引擎的核心执行者。
> **原则**：数据驱动，Draft 和正式分离，可晋升可降级可淘汰。

## 1. 架构概览

```
任务执行
  ↓
归藏交付 / 镜衡打回
  ↓
[复盘信号] → 执行 Agent 写复盘 → shared-knowledge/reviews/
  ↓
溶萃 cron 扫描（每天/每周）
  ↓ 同类经验 ≥3 次
蒸馏成 Skill Draft → shared-knowledge/skill-drafts/
  ↓ skill_manager 注册 → 下次任务自动注入
  ↓ 使用 ≥3 次 + 成功率 > 80%
晋升为正式 Skill → ~/.agents/skills/ 或对应部门 Skill 目录
  ↓ 使用 ≥5 次 + 成功率稳定
固化（加入 Agent 默认 SOUL.md 或 SKILL.md）
```

## 2. 数据结构

### 2.1 任务复盘记录
```markdown
<!-- 路径: {项目}/.openclaw-project/reviews/{agent_id}-{timestamp}.md -->
## 任务复盘
- 任务ID: [ID]
- Agent: [代号]
- 结果: ✅ 通过 / 🚫 打回
### 做了什么
### 遇到什么问题
### 怎么解决的
### 下次应该怎么做
### 差距归因
```

### 2.2 Skill Draft 模板
```markdown
# Skill Draft: {名称}
## 元数据
- 创建者: 溶萃
- 来源复盘: [复盘文件列表]
- 适用 Agent: [锋铸/墨卿/绘象/...]
- 适用场景: [描述]
- 状态: 草稿/已验证/晋升候选/已晋升/已降级/已淘汰
## 触发条件
## 核心步骤
## 示例
## 反模式
## 验证方法
## 使用统计
```

## 3. 复盘触发机制
- 归藏（Layer 6 交付）→ 标准复盘
- 镜衡（Layer 5 打回）→ 深度复盘（含根因分析）

## 4. 经验蒸馏（溶萃驱动）
- 每天扫描 reviews/ -> 聚类 ≥3 次同类经验 -> 创建 Draft
- 每周输出进化报告 + 晋升审查 + 降级/淘汰清理

## 5. Skill 进化管理
- 草稿 → 使用≥3次 → 已验证 → 成功率>80% → 晋升候选 → 溶萃审查 → 已晋升 → 使用≥5次 → 已固化
- 打回率>30% → 降级
- 连续30天未触发 → 淘汰

## 6. 进化节奏
- 每次任务: Layer 1 复盘 + skill_manager 记录
- 每天: 溶萃扫描 + 创建 Draft
- 每周: 进化报告 + 晋升审查 + 降级/淘汰清理

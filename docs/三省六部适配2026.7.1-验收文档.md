## 验收项 1：子 Agent Session 自动标题（P1）

### 变更内容
- 为所有三省六部子 Agent 配置 `utilityModel`，使子 Agent session 自动生成描述性标题
- 替代当前空白/generic 标题，提升 Dashboard 可辨识度

### 验收标准

| # | 检查项 | 预期结果 | 验证方式 |
|---|--------|---------|---------|
| 1.1 | utilityModel 配置生效 | 子 Agent session 有描述性标题（非空白） | `openclaw sessions --all-agents --active 5` 查看标题 |
| 1.2 | 不影响主 Agent | 主 Agent (鮱澄) session 标题仍由手动/系统控制 | 主 session 标题不受 utilityModel 干扰 |
| 1.3 | 低成本 | utilityModel 使用 flash 级模型 | `openclaw --status` 确认 model 路由 |
| 1.4 | 不影响响应速度 | 子 Agent spawn 到返回时间 ≤ 15s | 手动 spawn 测试 |

## 核心职责：系统进化（最高优先级）

### 每天执行
```
cron 触发 → 扫描所有项目 reviews/ 目录
  ↓
按 Agent + 差距归因 + "下次应该怎么做" 聚类
  ↓
同类经验 ≥3 次 → 蒸馏成 Skill Draft
  ↓
写入 shared-knowledge/skill-drafts/
  ↓
通知 skill_manager 注册
```

### 每周执行
```
输出进化报告（模板见 EVOLUTION.md 7.4）
  ↓
检查晋升候选（已验证 + 成功率 > 80%）
  ↓
执行晋升审查 → 通知总办确认
  ↓
检查降级/淘汰条件 → 执行
  ↓
清理 _retired/ 中 >90 天的淘汰 Skill
```

### Skill 蒸馏标准
- 来源 ≥3 次复盘
- 触发条件明确
- 核心步骤可执行（不是描述性知识）
- 有反模式
- 和现有 Skill / GOVERNANCE.md 无冲突

### 蒸馏产出格式
```markdown
# Skill Draft: {名称}

## 元数据
- 创建者: 溶萃
- 来源复盘: [复盘文件列表]
- 适用 Agent: [锋铸/墨卿/绘象/...]
- 适用场景: [描述]
- 状态: 草稿

## 触发条件
## 核心步骤
## 示例
## 反模式
## 验证方法
```

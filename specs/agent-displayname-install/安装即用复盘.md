- `register_agents` / `ensure_agents_registered` 对已存在 Agent **只跳过不更新 name**。
- **推论**: 若用户在旧版已装这套体系（Agent 为旧名），升级后 openclaw.json 的 name 字段**不会**自动改成方案 A（文件层 SOUL/AGENTS 会更新，但 openclaw.json name 保持旧名 → 两处不一致）。

- **状态**: 保持现状（改名靠迁移脚本完成），本报告记录备查。

## 〇、核心原则（技术边界，绝不能破）

以下**保持完全不变**，改了会导致全系统崩溃：
1. **英文 ID 不变**：`taizi / zhongshu / menxia / shangshu / libu_hr / libu / bingbu / gongbu / xingbu / hubu / zaochao`
2. **状态机 key 不变**：`Pending → Taizi → Zhongshu → Menxia → Assigned → Doing → Review → Done`
3. **OpenClaw Agent ID 不变**：`main / ld-r / guihua / shenyi / paifa / wenan / daima / sheji / shencha / huizong / rongcui`
4. **API 路径/参数不变**：`/api/create-task`、`/api/advance-state`、`taskId / action / state` 等
5. **CSS 是动态拼 class**：前端 `'dt-'+t.org` 按 org **字符串**拼 CSS class——所以 org label 变了，CSS class 名也要同步改，但**逻辑不用动**（class 随 org 字符串自动对应）

> 一句话：**动的是「中文显示 label + 文案」，不动的是「英文 key + 状态机 + API + Agent ID」。**
